# BrainDo

Um aplicativo mobile de gerenciamento de tarefas desenvolvido na Unity, com foco em uma interface de usuário responsiva e armazenamento offline.

## Sobre o Projeto

O BrainDo foi construído utilizando as ferramentas de interface modernas da Unity para criar uma experiência fluida em dispositivos móveis. O aplicativo permite o controle e a organização de tarefas diárias, garantindo que as informações não sejam perdidas ao fechar o app por meio de um sistema de salvamento nativo.

## Tecnologias Utilizadas

*   **Engine:** Unity
*   **Interface de Usuário:** UI Toolkit (UXML e USS)
*   **Linguagem:** C#
*   **Persistência de Dados:** Armazenamento local estruturado utilizando serialização em JSON
